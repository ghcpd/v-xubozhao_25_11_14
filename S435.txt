## 🔍 Analysis — What I found
File inspected: buggy_model.py.

Problems detected (functional bugs and constraint-handling):
- 1) Wrong formula:
  - The function used `score = age + credits` when it should compute `score = age * 2 + credits // 10`.
- 2) Constraint checking:
  - Age incorrectly allowed negative ages and ages outside the intended 0–120 range.
  - Credits incorrectly allowed negative credits and credits above 10,000.
- 3) Wrong behavior / unbounded scores:
  - No enforcement of `score` cap at `5000`.
  - No Type validation for inputs (floats/strings).
- 4) Meaningless/misleading check:
  - The original had `if age > 200: score = -1` — not only incorrect but inconsistent with intended constraints.

Intended behavior in docstring:
- Age: integer in [0, 120]
- Credits: integer in [0, 10000]
- Score: `age * 2 + credits // 10`, but capped at 5000
- Invalid inputs should raise an error (I used TypeError for wrong types and ValueError for invalid ranges).
